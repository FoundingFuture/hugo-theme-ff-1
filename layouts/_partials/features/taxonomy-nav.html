A topic is somewhere you are; a term is a filter you apply, and the two read differently, so the terms are laid out as marks rather than as rows. Every name and count comes from Hugo, so a site that defines its own taxonomies gets them here without configuring anything, and a site whose taxonomy has no terms gets nothing. A term links to its own page. .RelPermalink carries the site's own path prefix, which a hand-written /tags// would not. */ -}} {{- $page := . }} {{- $out := slice }} {{- range $name, $terms := site.Taxonomies }} {{- with site.GetPage (printf "/%s" $name) }} {{- if .Pages }}{{ $out = $out | append . }}{{ end }} {{- end }} {{- end }} {{- with $out }}
