That menu is the menu, walked to whatever depth its parent keys describe, and the content tree is not shown beneath it. A site that defines none gets its own folders, however deep they go, with nothing to configure. Hugo's guidance to theme authors is not to hardcode section names, so a folder added tomorrow appears by itself. A section stays out of the list by saying so in its front matter: build: list: never render: always which keeps its url and keeps its pages in search. A theme cannot contribute menu entries. menus is a slice, and Hugo merges maps from a theme but never slices, so the content tree can never become real menu entries however it is built. sectionPagesMenu = 'main' fills that menu with top-level sections and nothing below them.
